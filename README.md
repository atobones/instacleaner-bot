# InstaCleaner Bot 🚀

Telegram bot that turns Instagram links into a clean **preview-only video card** (no ugly link in chat) and lets users **share** it in 1 tap.

## Features
- Clean preview-only video card from Instagram links
- No link spam in chat
- One-tap Share button (Telegram share URL)
- Lightweight and easy to deploy

## Setup
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
